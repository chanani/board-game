## 1. 점수 규칙 수정(#10) — 공식 규칙

공식 규칙(rulespal Paper Safari rulebook): "같은 열의 두 카드 값이 같으면 그 열은 0", "사파리(와일드) 카드는 바로 왼쪽 또는 오른쪽 카드와 같은 값으로 친다(소유자에게 유리한 쪽)".

- 판은 2줄(row) × 3열(column). 와일드는 **같은 줄의 왼쪽/오른쪽 이웃 칸** 값을 복사한다. 이웃이 와일드면 그 와일드가 정한 값을 따른다(연쇄). 이웃이 없는 쪽은 고를 수 없다.
- 판 전체 합이 **가장 낮아지는** 복사 조합을 고른다(와일드는 덱에 2장뿐이므로 모든 조합을 시도해도 된다).
- 한 줄이 전부 와일드처럼 복사할 실제 값이 없으면 그 와일드는 0.
- 값이 정해진 뒤 열 점수: 위·아래 값이 같으면 0, 아니면 합. 여우 두 장(-2,-2)도 0(공식 규칙).
- 예: 윗줄 [-2, 와일드, 와일드] → [-2, -2, -2]. 각 열은 아랫줄 카드와 비교해 계산.
- 백엔드: `ColumnScore` 대신 판 단위 `BoardScore`(와일드 해석 → 열 점수 합). `RoundResult`/결과 점수가 이것을 쓴다.
- 프론트: `score.ts`에 같은 알고리즘(`resolveWilds(board)`, `boardScore`, 열별 점수). 결과 화면 열 배지와 합계, 게임 중 예상 점수(보이는 카드만: 가려진 칸은 와일드의 이웃 후보에서 제외, 가려진 칸 수는 기존처럼 "+ 가려진 N장")가 같은 함수를 쓴다.
- 결과 화면 열 배지 아래에 와일드가 복사한 값을 작은 글씨로 표시("와일드 → -2").

## 2. 턴 타이머(#6)

- 행동을 기다리는 모든 단계에 **15초** 제한: 시작 뒤집기(SETUP_FLIP, 아직 안 뒤집은 사람 각각), 가져오기(DRAW), 놓기(PLACE), 코끼리 엿보기(PEEK).
- 서버가 시간을 잰다(권위). 상태가 바뀔 때마다 마감 시각을 새로 잡는다. 시간 초과 시 서버가 그 사람 대신 행동한다(연결이 끊긴 사람도 같음):
  - SETUP_FLIP: 아직 안 뒤집은 사람마다 뒷면 칸 중 무작위 1장 뒤집기.
  - DRAW: 버린 카드 더미 맨 위를 가져와 내 6칸 중 무작위 칸과 교체(더미가 비었으면 덱에서 뽑아 무작위 칸과 교체).
  - PLACE: 들고 있는 카드를 무작위 칸과 교체.
  - PEEK: 뒷면 칸 중 무작위 1장 엿보기(뒷면이 없으면 넘김).
- 뷰에 `deadline`(epoch ms, 행동을 기다리는 단계에서만, 아니면 null)과 `serverNow`(epoch ms)를 넣는다. 클라이언트는 `deadline - serverNow`로 남은 시간을 계산해(시계 차이 보정) 1초 단위로 표시한다.
- 화면: 남은 시간이 **5초 이하**일 때부터 차례 안내 바와 해당 플레이어 이름표에 원형 카운트다운(숫자 + 줄어드는 링)이 나타난다. 내 차례면 짧은 경고음(무음 설정 존중).
- 구현: Spring `TaskScheduler`로 방별 예약 작업 1개. 예약 작업은 `RoomService`의 같은 전역 잠금 안에서 "마감이 아직 유효한지(상태 버전 비교)" 확인 후 자동 행동 → 브로드캐스트 → 결과 이벤트. 방이 사라지거나 게임이 끝나면 예약 취소.
- 무작위는 주입 가능한 `Random`(테스트에서 고정).

## 3. 방 테마(#1)

- 테마 5종: `WOOD`(원목 라운지, 기본) · `SUNSET`(사바나 노을) · `MOONLIT`(달빛 정글) · `AURORA`(설원 오로라) · `BLOSSOM`(벚꽃 정원). 시안의 색·배경 그대로.

- 프론트: 방 화면 최상위에 `data-theme`를 두고 CSS 변수(배경, 테이블 펠트 그라데이션, 테두리 2색, 카드 뒷면 무늬 2색 + 중앙 문장 색, 강조색/강조 그림자, 상태 바 배경, 글자색)를 테마별로 정의. `Felt`, `CardBack`, 강조 버튼, 상태 바, 이름표 강조가 변수를 쓴다. 로비·게임 목록 등 방 밖 화면은 기존 원목 테마.
- 방 만들기 창에 테마 선택(5개 미리보기 타일, `role="radiogroup"`), 로비 방 목록 항목에 테마 색 점 + 이름.

## 4. 방 화면 재구성(#2, #4, #11, #13, #14)

- **상태 바(대기실·게임 공통, 방 맨 위)**: 방 이름 + 칩(게임, 상태, 인원(사람 아이콘), 관전(망원경 아이콘), 비공개(자물쇠 아이콘)) + 오른쪽 코드 복사 칩(대기 중만) + 진행 기록 버튼(게임 중) + 나가기. 기존 방 머리글을 대체.
- **대기실**: 테이블 위에는 자리(의자)만. 준비/시작/관전자 안내/자리에 앉기/코드는 테이블 위에서 빼서, 준비·시작은 **테이블 아래 행동 바**(종이 카드: 왼쪽 "준비 n/m · 이유 문구", 오른쪽 주 버튼), 코드는 상태 바로.
- **게임 화면**: 상태 바 아래 **차례 안내 바**(차례 문구 + 타이머 + 최근 진행 내역 한 줄)를 테이블과 16px 이상 띄워 배치(#4). 테이블 안 덱·버린 카드 묶음과 내 판 사이 간격 확대(#13, PC 32px 이상). 모바일: 안내 바 글씨 `text-xs`, 패딩 축소, 한 줄 말줄임(줄바꿈 금지, #14).
