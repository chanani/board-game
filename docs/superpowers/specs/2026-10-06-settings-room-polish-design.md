## 1. 준비 버튼 전환 애니메이션 (#1)

- 대기실 행동 바의 준비 버튼(`room/WaitingActionBar.tsx`): "준비하기"(노랑, primary) ↔ "준비 취소"(회색, muted).
- 누르면 버튼이 0.92배로 눌렸다가 1.06배로 튕겨 1배로 돌아온다(약 0.4초, spring). 색은 같은 시간 동안 바뀐다.
- "준비 취소" 상태에는 글자 앞에 초록 체크 아이콘이 있고, 체크는 선이 그려지듯 나타난다(pathLength 0→1). 글자는 아래에서 6px 올라오며 나타난다.
- 취소하면 반대로(체크 없이 "준비하기"가 올라옴).
- 자리 이름표의 "준비 완료" 배지(`room/MemberList.tsx`)는 나타날 때 0.6배 → 1배로 톡 튀어나온다.

## 2. 태블릿은 PC 배치 (#2)

- `lib/useTableLayout.ts`의 판정을 바꾼다. 순서: 휴대폰을 눕힌 화면(`(orientation: landscape) and (max-height: 540px)`) → `landscape`; 폭 768px 이상 → `pc`; 그 밖 → `portrait`.
- `tablet` 값과 `TableRound`의 `compact` 밀도는 쓰이지 않으므로 지운다.
- 640~767px 화면은 세로 휴대폰처럼 `mini` 테이블을 쓴다(PC 테이블은 768px보다 좁으면 상대 판이 넘친다).
- 게임 화면의 `wide`(차례 안내 긴 문구, 안내 바 크기)는 `layout === 'pc'`를 따른다.

## 3. 게임 중 칩 삭제 (#3)

- 방 상태 바(`components/RoomStatusBar.tsx`)에서 게임 중일 때 "게임 중" 칩을 그리지 않는다. 대기 중일 때 "대기 중" 칩은 그대로.

## 4. 설정 페이지 (#4, #5)

- 새 경로 `/settings`(로그인 필요, 공통 레이아웃 안). 상단 메뉴에 "설정" 탭(톱니 아이콘 + 글자, 모바일은 아이콘 + 짧은 글자)을 "전적" 다음에 둔다.
- 헤더의 소리 켜기/끄기 버튼과 로그아웃 버튼을 없앤다(닉네임 표시는 유지).
- 설정 페이지 구성(종이 패널):
  - **소리**: 효과음 켜기/끄기 토글(`ToggleSwitch`), 음량 막대 0~100(`input type="range"`, 숫자 함께 표시, 효과음이 꺼져 있으면 흐리게 + 비활성), "소리 들어보기" 버튼(`myTurn` 소리 재생).
  - **계정**: 닉네임, 아이디, 로그아웃 버튼(빨강, 가로 꽉 차게).
- 음량은 `localStorage` 키 `bg.volume`(정수 0~100, 기본 70, 읽기·쓰기는 try/catch). 소리 엔진(`lib/sound.tsx`)은 모든 소리를 하나의 주 음량 노드(GainNode)를 거쳐 내보내고, 음량 값 / 100을 곱한다. `SoundApi`에 `volume: number`, `setVolume(value: number)` 추가(0~100 범위로 자른다).

## 5. 로그아웃 확인과 게임 중 기권 (#6, #7)

- 로그아웃 버튼을 누르면 확인 창(Modal)을 띄운다.
  - 내 방(`roomsApi.mine()`)이 게임 중이고 내가 그 게임의 참가자(관전자 아님)면: 제목 "게임 중이에요", 본문 "지금 로그아웃하면 진행 중인 게임은 기권 처리되고 방에서 나가요. 그래도 로그아웃할까요?", 버튼 "계속 게임하기" / "기권하고 로그아웃".
  - 그 밖: 제목 "로그아웃할까요?", 본문 "다음에 다시 로그인하면 이어서 즐길 수 있어요.", 버튼 "취소" / "로그아웃".
- 서버: `/api/auth/logout` 로그아웃 처리기에 "이 회원이 들어가 있는 방에서 나가기"를 추가한다(`RoomService.leaveCurrentRoom(memberId)`: 방이 없으면 아무것도 하지 않음, 있으면 기존 `leave`와 같은 처리 — 게임 중이면 기권, 대기 중이면 나가기, 관전이면 관전 끝). 그래서 화면 확인 없이 다른 창에서 로그아웃해도 게임이 멈추지 않는다.
- 프론트는 확인 후 기존 로그아웃 API만 부른다(기권은 서버가 한다). 로그아웃이 끝나면 로그인 화면으로.

## 6. 방 설정 변경 (#8)

- API: `PATCH /api/rooms/{code}/settings`, 본문 `{ maxPlayers: number, theme: RoomTheme }`, 응답 방(RoomResponse). 바뀐 방은 방 안 모두에게 방송하고 로비 목록에도 반영된다.
- 규칙(도메인 `Room.reconfigure(requesterId, Capacity, RoomTheme)`):
  - 방장만(`NOT_ROOM_HOST`), 대기 중일 때만(게임 중이면 `ROOM_ALREADY_PLAYING`).
  - 최대 인원은 게임 종류 범위(`Capacity.of`, 아니면 `INVALID_CAPACITY`)이고, 지금 참가자 수 이상(아니면 새 오류 `CAPACITY_BELOW_PLAYERS`).
  - 테마는 지원하는 값(`INVALID_THEME`).
  - 인원을 늘리면 자리를 기다리던 관전자를 기존 규칙대로 앉힌다.
  - 준비 상태는 그대로 둔다. 비밀번호·방 이름은 바꾸지 않는다.
- 화면: 대기 중이고 내가 방장이면 상태 바 첫 줄(코드 칩 옆)에 "방 설정" 버튼(톱니 아이콘, 좁은 화면은 아이콘만 + `aria-label`). 누르면 "방 설정" 창: 최대 인원(방 만들기와 같은 SeatPicker, 지금 참가자 수보다 적은 칸은 비활성 + 안내 "지금 N명이 있어서 M명 이하로는 줄일 수 없어요."), 테마(ThemePicker), 버튼 "취소" / "저장". 저장 중에는 버튼 비활성, 실패하면 오류 토스트.
- 테마가 바뀌면 방 배경(`RoomBackdrop`)이 0.4초 동안 겹쳐 사라지며 바뀐다.

## 7. 엿본 카드 표시 (#9)

- 코끼리 효과로 엿본 내 카드(`known && !faceUp`, 카드 값이 있음)는 앞면을 또렷하게 그린다(지금처럼 뒷면 위에 45% 겹치지 않는다).
- 공개된 카드와 구분: 보라색 점선 테두리(`outline 3px dashed`, violet-400, offset 2px) + 카드 아래 가운데 "엿봄" 꼬리표(보라 배경, 흰 글씨 9~10px). 기존 돋보기 배지는 없앤다.
- 카드 접근성 이름은 지금처럼 "… 카드 (엿봄)".
- 엿보기가 일어나 카드가 처음 엿본 상태가 되면 살짝 들렸다 내려오는 연출(위로 8px, 약 0.35초)을 한 번 한다.
- 다른 사람 화면에서는 여전히 뒷면(서버가 값을 보내지 않음).

## 8. 모바일 내보내기 버튼 (#10)

- PC(폭 1024px 이상)가 아닐 때:
  - 대기실 자리(`room/MemberList.tsx`)의 방장 내보내기 버튼은 아바타 오른쪽 위에 겹친 지름 20px 빨간 동그라미 X 버튼으로 바꾼다(흰 테두리 2px, 누르는 영역은 32px). `aria-label="{닉네임}님 내보내기"`. 누르면 지금처럼 확인 창.
  - 게임 중 연결 끊긴 사람의 내보내기 버튼(`PlayerBoard`)도 이름표 옆 같은 작은 X 버튼으로 바꾼다(`aria-label` 동일 형식).
- PC는 지금 글자 버튼 그대로.

## 10. 테스트

- 백엔드: `Room.reconfigure`(방장 아님, 게임 중, 인원 미만, 범위 밖, 정상 변경·테마 반영, 인원 늘리면 관전자 착석); `PATCH /settings` 컨트롤러(성공 응답, 오류 응답 형식); 로그아웃 시 게임 중이면 기권되어 남은 사람에게 방송, 대기 중이면 방에서 빠짐, 방이 없으면 그대로 로그아웃.
- 프론트: 준비 버튼 상태별 체크 아이콘·색; 레이아웃 판정(눕힘 → landscape, 768px 이상 → pc, 그 밖 → portrait); 게임 중 칩 없음; 설정 페이지(토글, 음량 저장·복원·범위 자르기, 효과음 끔이면 막대 비활성, 들어보기 재생); 헤더에 소리·로그아웃 버튼 없음, 설정 탭 있음; 로그아웃 확인 창 두 가지 문구와 확인 후 로그아웃 호출; 방 설정 버튼은 방장·대기 중에만, 창의 인원 비활성 칸·저장 호출; 엿본 카드는 앞면 + "엿봄" 꼬리표 + 점선 테두리, 돋보기 배지 없음; 모바일 내보내기는 X 버튼·aria-label, PC는 글자 버튼.
- 최종: 실제 브라우저로 PC·태블릿(768px)·휴대폰 세로·가로 확인(30분 이내, 진행 상황을 중간에 남긴다).
