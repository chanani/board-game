## 1. 게임 중 채팅을 늘 보이게 (#1, A안)

- **PC(폭 1024px 이상, 기존 `PC_QUERY`)**: 게임 화면을 `테이블 | 채팅 칸` 두 칸으로 나눈다. 채팅 칸은 너비 260px 종이 패널로 늘 열려 있고(기존 `ChatPanel` 재사용: 메시지 목록 + 입력칸), 새 메시지가 오면 아래로 자동 스크롤, 보이는 동안 읽음 처리. 높이는 테이블 영역과 같게(화면 높이에 맞춰 목록만 스크롤). 떠 있는 말풍선 버튼과 오른쪽 서랍은 게임 중에 쓰지 않는다.
- **PC가 아닐 때(세로 휴대폰, 태블릿)**: 테이블 바로 아래에 "채팅 줄" 종이 카드 — 최근 메시지 3개를 한 줄씩(닉네임 굵게 + 관전 배지(관전자) + 내용, 넘치면 말줄임, 내 메시지는 "나") + 입력칸과 보내기 버튼. 메시지 줄 영역을 누르면 기존 전체 채팅 시트(아래에서 올라오는 시트)가 열린다. 메시지가 없으면 "아직 대화가 없어요." 한 줄. 떠 있는 말풍선 버튼은 없앤다.
- **휴대폰을 눕힌 화면(landscape)**: 왼쪽 정보 칸(상태 바·차례 안내 아래)에 같은 채팅 줄을 둔다.
- 대기실 채팅은 지금 그대로(대기실은 이미 채팅 패널이 보인다).
- 게임이 끝나 결과 창이 떠 있는 동안에도 채팅 칸/줄은 그대로 보인다.

## 2. 닉네임 메뉴 (#2)

- 헤더 오른쪽 닉네임을 버튼으로 바꾼다(닉네임 + 아래 화살표 아이콘, `aria-haspopup="menu"` 대신 `aria-expanded` + `aria-controls`의 펼침 패널). 누르면 아래로 펼침 패널(종이, 너비 약 260px, 오른쪽 정렬): 아이디(작게)·닉네임(굵게), 효과음 토글, 음량 막대(0~100, 숫자, 효과음 꺼짐이면 비활성), "소리 들어보기", 구분선, 로그아웃(빨강, 가로 꽉 차게).
- 바깥 클릭·Esc·같은 버튼 다시 누르기로 닫힌다. 열고 닫을 때 위에서 살짝 내려오는 애니메이션(진행 기록 팝오버와 같은 방식).
- 로그아웃은 지금과 같은 확인 창(게임 참가 중이면 기권 안내, 방 조회 실패 시에도 기권 안내)을 거친다.
- "설정" 탭과 `/settings` 페이지를 없앤다. `/settings`로 들어오면 `/`로 보낸다.
- 모바일도 같은 패널(화면 오른쪽 여백 16px 안에서 펼침, 화면 밖으로 넘치지 않음).

## 3. 기권하고 나간 사람 알림 (#3)

- 게임 중이던 방(이전 방 상태 `PLAYING`)에서 다른 참가자가 참가자 목록에서 빠지면(나가기·로그아웃·내보내기·자동 기권 모두):
  - 화면 위 알림(토스트, info): 그 사람이 마지막으로 연결 끊김 상태였으면 "연결이 끊겨 {닉네임}님을 기권 처리했어요", 아니면 "{닉네임}님이 기권하고 나갔어요". 닉네임은 이전 방 정보에서 가져온다(떠난 뒤에도 이름이 보이게).
  - 진행 기록에 같은 문구로 한 줄(새 종류 `leave`, 나가기 아이콘). 차례 안내 바의 최근 진행에도 보인다.
- 내가 빠진 경우에는 이 알림을 띄우지 않는다(기존 "방에서 나왔어요." 흐름 그대로). 관전자가 나가는 것은 알리지 않는다.
- 한 번의 방 갱신에서 여러 명이 빠지면 사람마다 한 줄씩.

## 4. 채팅 관전 표시 (#4)

- 채팅 메시지 머리줄을 `닉네임 → 관전 배지` 순서로 바꾸고, 두 요소의 높이를 맞춘다(같은 줄 높이 18px, 세로 가운데 정렬). 관전자 닉네임 색(하늘색 계열)은 유지. 채팅 줄(#1 모바일)에서도 같은 순서.

## 5. 방 목록에서 내 방은 "돌아가기" (#5)

- 원인: 게임 로비의 방 목록이 내가 그 방에 들어가 있는지 보지 않고, 게임 중인 방에는 늘 "관전하기"를 보여 줬다(다른 기기에서 로그인해 목록을 보면 내 게임 방이 "관전하기"로 보임).
- 로비는 내 방(`roomsApi.mine()`, 목록을 새로 고칠 때 함께 갱신)을 알고, 목록의 그 방 카드에는 "참가"/"관전하기"/"가득 참"/"비공개" 대신 "돌아가기" 버튼(누르면 `/rooms/{code}`로 이동)과 "참여 중" 표시를 둔다. 대기 중·게임 중 목록 모두.

## 6. 게임 중 연결이 1분 넘게 끊기면 자동 기권 (#6)

- 서버가 게임 중인 방의 참가자를 주기적으로(5초마다) 확인해, 연결이 끊긴 지 60초 이상인 참가자를 그 방에서 나가게 한다(기존 `leave` — 게임 중이면 기권, 결과·전적 처리, 방송, 차례 타이머 재설정 포함). 다시 연결되면 끊긴 시각이 지워지므로 대상이 아니다.
- 대기실·관전자는 대상이 아니다(대기실은 지금처럼 방장이 내보낸다).
- 구현: `RoomService.forfeitLongDisconnected()`(전역 잠금 안에서, 게임 중인 방마다 60초 이상 끊긴 참가자 목록을 먼저 모은 뒤 한 명씩 `leave`). 주기 실행은 별도 컴포넌트가 `TaskScheduler`로 5초 간격 고정 지연 실행한다. 설정 속성 `app.disconnect-forfeit.enabled`(기본 true)로 끄고 켤 수 있고, 테스트 설정에서는 끈다(테스트는 메서드를 직접 부른다).
- 게임 화면의 "연결 끊긴 사람 직접 내보내기" 버튼(PlayerBoard의 기권 버튼·X 배지)은 없앤다(60초가 되면 서버가 처리하므로). 대기실 자리의 내보내기와 서버 API(`/members/{id}/forfeit`)는 그대로 둔다.
- 다른 사람에게는 #3 알림("연결이 끊겨 …님을 기권 처리했어요")이 뜬다.

## 7. 테스트

- 백엔드: `forfeitLongDisconnected` — 60초 이상 끊긴 게임 참가자만 기권·퇴장(59초는 그대로, 다시 연결되면 그대로, 대기실 방은 그대로, 관전자는 그대로, 2인 게임에서 한 명이 빠지면 게임 끝·남은 사람 대기 상태), 결과 이벤트 발행. 속성이 false면 주기 실행이 등록되지 않음.
- 프론트: PC 게임 화면에 채팅 칸이 늘 보이고 말풍선 버튼 없음, 모바일 채팅 줄(최근 3개, 관전 배지 순서, 보내기, 줄 누르면 시트), 눕힌 화면은 왼쪽 칸에 채팅 줄; 닉네임 메뉴(열기·닫기·Esc·바깥 클릭, 소리 조절, 로그아웃 확인), 설정 탭 없음·`/settings` → `/`; 기권 알림(두 문구, 내가 나간 경우·관전자·대기 중에는 없음, 진행 기록 `leave`); 채팅 머리줄 순서와 높이 클래스; 로비 내 방 "돌아가기"; 게임 화면에 기권 버튼 없음.
- 최종: 실제 브라우저로 PC·모바일 게임 채팅, 닉네임 메뉴, 두 계정으로 기권 알림 확인(30분 이내).
